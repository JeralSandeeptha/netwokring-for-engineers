# Types of Networks

## PAN – Personal Area Network

- Definition: A short-range network for personal devices.
- Connection Type: Bluetooth, infrared, USB.
- Range: 1–10 meters.
- Example: Connecting your phone to wireless earbuds or smartwatch.

## LAN – Local Area Network

- Definition: A network connecting computers in a limited area like a home, office, or building.
- Connection Type: Usually wired (Ethernet).
- Range: A few meters to a few kilometers.
- Speed: Very high (e.g., 1 Gbps or more).
- Example: Office computers connected to a central server via Ethernet.

## WLAN – Wireless Local Area Network

- Definition: A type of LAN that uses wireless (Wi-Fi) instead of cables.
- Connection Type: Wireless.
- Range: Around 50–100 meters indoors.
- Speed: High (depends on Wi-Fi standard; e.g., Wi-Fi 5, 6).
- Example: Home Wi-Fi network connecting phones, laptops, and smart TVs.
- LAN vs. WLAN: WLAN is a wireless form of LAN. LANs can be wired or wireless; WLANs are always wireless.

## MAN – Metropolitan Area Network

- Definition: A network that spans a city or large campus.
- Connection Type: Fiber optics, microwave, wireless.
- Range: Typically 5–50 km.
- Example: City-wide Wi-Fi, university campus networks.

## WAN – Wide Area Network

- Definition: A network spanning large geographic areas, connecting multiple LANs/WLANs.
- Connection Type: Leased lines, satellite, or the internet.
- Range: Global.
- Speed: Slower than LANs (due to long distances).
- Example: The Internet, company intranet across countries.
