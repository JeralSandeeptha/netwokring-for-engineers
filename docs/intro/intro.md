# Introduction

## Why do we need Networking

- We do have a software which monolith bundle but too heavy and complex
- Machines also expensive. For simplicity we separate into two which are client and server
- Then those will be lightweight
- Clients can do lightweight tasks and servers can do expensive tasks. But now client and server needs to talk to each other
- That's why we need a communication tool but it should be a standard otherwise each other couldn't know what's happening
- That's how `RPC` `(Remote Procedure Call)` was born
